# ABTalks 60-Day Challenge Redesign

A mobile-first redesign of the ABTalks 60-day coding challenge platform, built for the hackathon.

## Live Demo

https://hackathon-abtalks.vercel.app/

## Routes

- `/`
- `/dashboard`
- `/day/12`

## Features

- 60-day challenge landing page
- Student dashboard with streak and progress
- Daily challenge and proof submission
- GitHub and LinkedIn submission validation
- First-day, missed-day, and empty-profile states
- Focus mode and recovery UX
- Mobile-first design for 390px viewport

## Tech

- HTML
- CSS
- JavaScript
- Vercel
- Mock data / frontend-only state
